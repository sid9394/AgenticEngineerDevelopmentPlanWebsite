Weeks 1–2 · Foundation Depth

LLM Internals + RAG Pipeline Mastery

You've used these in production. Now you need to be able to explain the mechanics under pressure. This week is about building a mental model you can draw from memory on a whiteboard.

Suggested order for Week 1:
Day 1–2: Transformer basics (3Blue1Brown + Illustrated Transformer) → Day 3: Build GPT from scratch (Karpathy) → Day 4: Tokenization deep dive → Day 5–7: RAG pipeline (DeepLearning.AI course + Anthropic cookbook). Run code alongside every video.

Start here — everything else depends on understanding how transformers work. Q/K/V matrices, attention scores, why we scale by √d_k, what multi-head attention actually does. You need to be able to explain this with a diagram in an interview.

All 8 Weeks · Daily

DSA: Daily Practice

One NeetCode 150 medium per day, every day. This is the non-negotiable daily quest. These resources are your complete DSA toolkit — from learning the patterns to timed practice.

Strategy: Pattern recognition over memorisation
Don't try to memorise solutions. Learn the pattern (sliding window, two pointers, BFS, DP). Once you recognise a pattern, you can solve any variation. NeetCode's roadmap is ordered by pattern — follow that order.
NeetCode 150 Roadmap — neetcode.io
The 150 most important LeetCode problems, ordered by pattern and difficulty. The standard preparation resource for GCC and FAANG DSA rounds in 2026. Follow the order exactly — it's designed to build pattern recognition progressively.
★ Must-doPracticeFree1 problem/day
NeetCode YouTube Channel
Video solutions for every NeetCode 150 problem. When you're stuck for 30 minutes, watch the video. The explanations focus on pattern recognition, not trick solutions. Subscribe and watch alongside your daily problem.
★ Must-doVideoFreePer problem
Blind 75 — LeetCode Discussion
The 75 most frequently asked interview problems. A subset of NeetCode 150. If you're short on time in Week 7–8, focus exclusively on these 75. Cover at least these before any interview.
